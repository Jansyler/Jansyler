### ⚙️ RigRadar — Market Intelligence SaaS
*Feb 2026 – Present*
* **Distributed Orchestration**: Built a fleet of Python and Node.js orchestrators for real-time market scanning, achieving sub-second data latency via WebSocket ingestion.
* **Rate-Limit Evasion**: Engineered proprietary anti-detection layers to bypass advanced JS challenges and fingerprint-based rate-limiting, sustaining 99.9% uptime against anti-bot grids.
* **Resilient Infrastructure**: Designed a fault-tolerant backend using Redis message queuing and PostgreSQL; integrated full-cycle Stripe billing with usage-based subscriptions and automated B2B affiliate tracking.

### 📱 Tapped In — High-Frequency Discovery Mobile App
*May 2026 – Present*
* **Cross-Platform Architecture**: Architected a mobile app (React Native/Expo) for high-frequency discovery of underground music, concerts, and fashion drops.
* **Computer Vision Pipeline**: Built a CV pipeline to analyze user photography and generate instant accessory recommendations via Grailed and Vinted marketplace integrations.
* **Data Aggregation**: Deployed high-availability scrapers aggregating Spotify, SoundCloud, TikTok, and goOut into a unified database with real-time geo-aware Apple/Google Calendar syncing.

### 📐 Sylenar — Custom CMS & Visual Engine
*Jan 2023 – Jun 2025 (Freelance / Freelancer)*

* **Cloud Deployment**: Designed scalable MySQL/PostgreSQL schemas for dynamic user-generated content with containerized Docker-based deployments.
